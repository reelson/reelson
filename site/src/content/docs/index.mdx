## Videos that don't go stale

<CardGrid>
    <Card title="The prompt is the spec" icon="pencil">
        Say what to show, in plain words. The agent writes a Playwright scenario, records it,
        words the callouts, checks the frames and renders the MP4.
    </Card>
    <Card title="Looks hand-made" icon="rocket">
        An eased, slightly imperfect cursor, uneven typing and zooms that follow the cursor. A
        branded intro, a recap and an outro, with your logo, colours and music.
    </Card>
    <Card title="Re-records in ~20 s" icon="random">
        After a redesign, `reelson verify --all` re-runs every demo headless. Callouts follow
        their markers and zooms follow their clicks, so nothing needs re-timing.
    </Card>
    <Card title="Every format" icon="laptop">
        16:9, a phone take for 9:16, a square take for 1:1, a GIF for the README, `.srt`/`.vtt`
        captions, an optional voice-over and one-command uploads to YouTube.
    </Card>
</CardGrid>

<p class="r-kicker">How it works</p>

## One scenario, one JSON file, one video

<div class="r-figure">
    <img src={pipeline.src} alt="scenario.ts → reelson record → recording.mp4 + markers.json → reelson build (with video.json, reelson.config.json, a template and sections) → video/, a HyperFrames project → reelson render → video/renders/<slug>.mp4, plus a GIF, portrait and square versions and captions" width="1060" height="430" />
</div>

You commit three small files per video: `scenario.ts` (what happens), `markers.json` (when it
happened) and `video.json` (how it looks). Everything else is generated.

<p class="r-kicker">Start in two minutes</p>

## Install, then ask

<Steps>

1. Install the CLI and link the skills into your agent:

   ```bash
   npm install -g reelson
   reelson install
   ```

2. Paste this into Claude Code, Codex or your agent, inside your project:

   ```text
   Make a demo video of <the feature>. The app runs on <http://localhost:3000>.
   Steps: 1. … 2. … 3. …  Title "<Title>". Slug <kebab-case-slug>.
   ```

3. Open `<videosDir>/<slug>/video/renders/<slug>.mp4`.

</Steps>
